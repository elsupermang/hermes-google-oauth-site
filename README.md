# Hermes Google OAuth site

Public homepage and privacy policy for the personal Hermes AI Digests automation.

- Homepage: https://ai.cyberrancho.com/
- Privacy policy: https://ai.cyberrancho.com/privacy.html

## GitHub Pages / DNS

The site is intended to be published from the `main` branch through GitHub Pages with the custom domain `ai.cyberrancho.com`.

At the DNS provider, create:

```text
Type: CNAME
Name: ai
Target: elsupermang.github.io
```

Do not put OAuth tokens, client secrets, refresh tokens, or personal account exports in this repository.
